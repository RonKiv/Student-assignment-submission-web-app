# [Project name]: School Assignment Submission System

Final project for **Web Application Development**, Kyungdong University (Fall 2026).
**Team:** Ronnie (project lead) · [Friend]

A school-wide web app where teachers post assignments, students upload their work before the deadline, and an admin manages courses and accounts.

## Run it on your laptop (Mac or Windows)
1. Clone this repo with **GitHub Desktop**.
2. Open the folder in **VS Code**. Install the recommended extensions when VS Code asks (Live Server and EditorConfig).
3. Right-click `index.html` → **Open with Live Server**.

Always use Live Server. Opening files by double-clicking them breaks logins.
